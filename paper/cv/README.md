# Computer-vision paper: one body, three venue wrappers

```
paper/cv/
  macros.tex            shared packages and macros; \input{../tables/numbers}
  body.tex              section order shared by every venue
  teaser.tex            figure* teaser (ECCV, TPAMI); cvpr/teaser_strip.tex for CVF page 1
  sections/             abstract, intro, related, method (+ gates), benchmark, experiments, limitations, supplement
  tables/               GENERATED by scripts/make_cv_tables.py from results/*.json (never edit by hand)
  figures/              GENERATED by scripts/make_cv_figures.py (teaser.png, close_strands.pdf, real_answered.png); method.tex (TikZ)
  references.bib        entries checked against CVF / publisher / arXiv pages on 2026-10-14
  cvpr/                 CVPR / ICCV: main.tex (8 pages + refs), supp.tex (separate PDF), rebuttal.tex, official CVF kit
  eccv/                 ECCV: main.tex (14 pages LNCS + refs), official ECCV kit
  tpami/                TPAMI (IEEEtran compsoc); for IJCV swap in Springer Nature's sn-jnl class
```

Build (from the venue folder): `latexmk -pdf main.tex`.
Refresh numbers and figures first:

```
python scripts/make_cv_tables.py
RAW_KNOT=<raw_knot folder> python scripts/make_cv_figures.py
```

## Moving between venues

| From the CVPR draft to | Change |
| --- | --- |
| ICCV | `\def\confName{ICCV}`, `\def\confYear{2027}`; same CVF kit and rules |
| ECCV | Build `eccv/main.tex`. 14 pages allow the per-session table, the risk-coverage plot and the style examples to move from the supplement into the paper. No appendix in the main PDF. Update `year=`/`ID=` in `\usepackage[review,...]{eccv}` and use that year's kit (font changes count against the limit). |
| TPAMI / IJCV | Build `tpami/main.tex` (IEEEtran is in TeX Live full and Overleaf; it is not installed here). Merge the supplement into the body, expand related work, add the real cable set, multi-view fusion, 3 seeds and the foundation-feature baseline. If it extends a conference paper, add a cover-letter summary of what is new. |

## Rules that bite (CVPR author guidelines)

- 8 pages including figures and tables; references extra; over-length is desk-rejected.
- Double-blind: no repository, Space or user names in the PDF, supplement or file metadata; code only via Anonymous GitHub.
- Supplement: no new datasets or improved-method results; it is a separate PDF (`cvpr/supp.tex`).
- Rebuttal: one page, `cvpr/rebuttal.tex`, no links, no new experiments unless asked.
- A dataset counts as a contribution only if public by camera-ready.
- Citations to non-existent work lead to rejection: re-check `references.bib` before submitting.
